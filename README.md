# Web Foundations Days

Welcome to the Web Foundations learning repository! This project tracks progress, daily exercises, and web applications built day by day.

## Contents

### [Day 1: QuickNotes](day1/)
A clean, lightweight note-taking web application built with semantic HTML5.
- **[day1/index.html](day1/index.html)**: QuickNotes homepage featuring note input and active notes list.
- **[day1/about.html](day1/about.html)**: About page with instructions, feature list, keyboard shortcuts table, and feedback form.

### [Day 2: CSS Styling & Layout](day2/)
Enhancement of QuickNotes with CSS3 styling, Flexbox navigation, CSS Grid responsive feature cards, styled forms, tables, and mobile responsiveness.
- **[day2/index.html](day2/index.html)**: Styled QuickNotes homepage with note entry, active notes list, and responsive layout.
- **[day2/about.html](day2/about.html)**: Styled about page with responsive feature cards, shortcuts table, and vertical feedback form.
- **[day2/style.css](day2/style.css)**: Shared stylesheet containing box-sizing reset, header & Flexbox nav styles, centred main, CSS Grid cards, table styles, form layout, button transitions, and `@media (max-width: 600px)` mobile rules.

### [Day 3: Notes Toolkit](day3/)
JavaScript exercises for searching, summarizing, validating, and managing notes.
- **[day3/index.html](day3/index.html)**: Notes Toolkit page that loads the Day 3 script.
- **[day3/script.js](day3/script.js)**: Note operations for searching, finding the longest note, counting categories, generating summaries, detecting duplicates, and adding validated notes.

### [Day 4: Draft Pad](day4/)
A responsive note editor with live counts, local draft saving, and a persistent light/dark theme.
- **[day4/index.html](day4/index.html)**: Draft Pad page with a labelled textarea, character and word counters, Clear button, and theme toggle.
- **[day4/style.css](day4/style.css)**: Responsive styles using CSS variables for light and dark themes, including character counter warning states.
- **[day4/script.js](day4/script.js)**: Live counters, warning thresholds, draft restoration and clearing, Escape-to-clear behavior, and theme persistence.
